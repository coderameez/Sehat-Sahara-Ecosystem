# SEHAT SAHARA — HOSPITAL & CLINIC DASHBOARD SPECIFICATION

You are building the standalone Hospital & Clinic Web Dashboard for "Sehat Sahara".
This application must look, feel, and function as an organic part of the existing Sehat Sahara health ecosystem.

## 1. TECH STACK
- Framework: React 18 (SPA) with TypeScript 5
- Build Tool: Vite
- Routing: react-router-dom v6
- Styling: Tailwind CSS v3 + Vanilla CSS reset
- Utilities: clsx, tailwind-merge
- Icons: lucide-react
- Font: Inter (via Google Fonts: 400, 500, 600, 700)
- State: Singleton Observable Store with subscribe/getSnapshot pattern + localStorage persistence

- Sidebar: Fixed 260px width, bg-white, border-r border-surface-border. Active item: bg-brand-50 text-brand-700 font-bold with brand-600 active accent bar or icon.
- Header: Sticky h-16, bg-white, border-b border-surface-border, px-6. Displays facility branch switcher, search, notifications bell with unread dot, and hospital staff profile avatar.
- Main Canvas: bg-surface-page (#F8FAFC), min-h-screen, p-6 space-y-6.
- Buttons: Pill shaped (rounded-full), h-10 px-5 text-sm font-semibold. Primary variant: bg-brand-600 text-white hover:bg-brand-700 shadow-sm. Secondary: bg-surface-section text-slate-700 hover:bg-slate-200.
- Inputs: h-11, rounded-xl, bg-white, border border-surface-border, focus:ring-2 focus:ring-brand-600/15 focus:border-brand-600 text-sm.
- Badges: rounded-full font-semibold px-2.5 py-1 text-xs:

## 6. DATA MODELS TO SUPPORT
- Facility (id, name, type: "HOSPITAL" | "CLINIC", logoUrl, branches)
- Branch (id, name, address, departments, services, doctors, hours, tokenSupport)
- QueueToken (id, patientId, patientName, tokenNumber, departmentId, status: "WAITING" | "CALLED" | "COMPLETED", issuedAt)
- Booking (id, patientId, providerId, facilityId, careType, scheduledDate, scheduledTime, status, fee)
- Provider (id, name, specialty, qualification, providerType, verificationStatus)
